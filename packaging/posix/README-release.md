# Ollama Configurator v0.1.16 — macOS/Linux ZIP

## Português

Este pacote usa os mesmos comandos no macOS e no Linux. Extraia o ZIP, abra o Terminal nessa pasta e execute:

```bash
chmod +x install.sh run.sh uninstall.sh
./install.sh
./run.sh
```

O `run.sh` mantém os logs do servidor visíveis no Terminal e abre o navegador da aplicação. Para remover o programa:

```bash
./uninstall.sh
```

A desinstalação remove somente os arquivos instalados. As configurações persistentes e os modelos do Ollama não são alterados. A API usa a porta 8787 e o gateway usa a porta 11435.

## English

This package uses the same commands on macOS and Linux. Extract the ZIP, open a Terminal in that folder, and run:

```bash
chmod +x install.sh run.sh uninstall.sh
./install.sh
./run.sh
```

`run.sh` keeps the server logs visible in the Terminal and opens the application browser. To remove the program:

```bash
./uninstall.sh
```

Uninstallation removes only the installed application files. Persistent settings and Ollama models are not changed. The API uses port 8787 and the gateway uses port 11435.
