# v0.1.11 Portable Packages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete v0.1.11 with platform-aware connection commands, bilingual Windows and macOS ZIPs, and verified release assets.

**Architecture:** A pure frontend helper selects the initial shell while preserving manual override. Platform-specific README sources are copied by the native packaging scripts. Each native GitHub runner builds, inspects, checksums, and publishes its own artifacts.

**Tech Stack:** React, TypeScript, Vitest, PowerShell, Bash, PyInstaller, GitHub Actions, `ditto`, GitHub CLI.

## Global Constraints

- Version remains exactly `0.1.11`.
- Windows uses `$env:OLLAMA_HOST="..."`; macOS/Linux use `export OLLAMA_HOST=...`.
- Unknown platforms default to POSIX; the selector remains manually overridable.
- READMEs contain complete Portuguese and English sections.
- Windows is x64; macOS is Apple Silicon (`arm64`).
- Do not bypass Gatekeeper, create an `.exe` installer, or add Authenticode signing.
- Preserve the DMG while adding both ZIPs.
